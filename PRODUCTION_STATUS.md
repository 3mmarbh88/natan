# NATAN Production Status

Updated 2026-09-28.

## Implemented in this build

- Production simulator is disabled. No random shifts are generated by `App.tsx`.
- The old simulator UI is no longer rendered from the main application.
- Real Ninja shift polling remains the source for detected shifts.
- Android `NatanAutomation` Capacitor plugin added.
- Android `NatanAccessibilityService` now has a production automation flow for the real Ninja package `com.mehedydev.nova`.
- The automation flow can open Ninja, navigate to the shifts screen, match a shift using NATAN's target data, click a booking action, detect a confirmation dialog, click Confirm, and require an explicit Ninja success message before NATAN records the shift as booked.
- Automation status is persisted in Android SharedPreferences and polled by NATAN so the result is returned to the web UI.
- Accessibility settings can be opened from the native plugin when the service is not enabled.
- Android coarse/fine location permissions were added.
- Location screen now contains a professional interactive OpenStreetMap picker with pan, zoom, manual point selection, and a native current-location action on Android.
- Selected latitude/longitude are persisted locally.
- The selected map point is a NATAN search/reference point. It does not spoof or alter Android GPS.
- The supplied NATAN logo is retained for the web/app icon assets.

## Validation

- `npm run lint` passes in the prepared source tree.
- A full Vite/Android build could not be completed in this execution environment because the supplied environment lacks the required Rollup Linux optional binary and the Gradle wrapper distribution is not locally cached. Run `npm install` and the Android build commands on the Windows development machine.

## Important runtime requirement

The real UI automation requires:

1. Ninja installed on the same Android phone.
2. The user logged into Ninja normally.
3. NATAN Accessibility Service enabled in Android Settings.
4. Android notification/location permissions granted when requested.
5. NATAN monitoring enabled and auto-booking enabled.

The automation intentionally does not bypass Play Integrity, Incognia, HMAC secrets, device integrity, or other Ninja security controls.


## Ninja APK analysis applied
- Verified Ninja API base: `https://api.samurai.delivery/api/v1`.
- Verified shift routes: `/captains/shifts`, `/captains/shifts/active`, `/captains/shifts/summaries`.
- Verified booking route family: `/shifts/booking/starting-points` and `/shifts/booking/{shiftId}/book`.
- Verified Ninja package used by the supplied APK: `com.mehedydev.nova`.
- NATAN keeps real booking in the Accessibility/UI path so it does not fabricate protected authentication or integrity material.
- Production simulator component removed from the active source tree.

## Location control update (2026-09-29)
- Added Android official Mock Location integration.
- The map can publish the selected latitude/longitude through Android's test GPS provider.
- Added controls: Apply to phone, Mock Location setup, Stop location.
- User must explicitly select NATAN as the Android Mock Location app in Developer Options.
- No attempt is made to hide mock-location state or bypass another app's anti-spoofing checks.
- If the other app rejects mock locations, that behavior remains under that app's control.
